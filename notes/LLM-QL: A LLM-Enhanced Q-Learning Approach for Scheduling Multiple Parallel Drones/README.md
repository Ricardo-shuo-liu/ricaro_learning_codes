LLM-QL: A LLM-Enhanced Q-Learning Approach for Scheduling Multiple Parallel  Drones
本研究针对多随行助手旅行商问题（mFSTSP）展开研究，该问题中并行无人飞行器（UAV）或无人机与卡车协同工作，以提升配送效率。
核心:
建立了LLM-QL架构，其实就是用LLM来启发式的减少QL的探索。
提供了一个提示词策略
搞了6个实验证明本方法不错
个人认为实现原因：
由于LLM的推理能力而且生成式的方法，在普遍的语料中学习到方法论，对于当前作用下即使没有语料训练也可以进行推理得到一个比较不错的数值。
相当于一个不那么专家的自动的专家的规则制定。

优势：
对于场景的要求极其低因为LLM的启发式不需要训练而且效果比较不错

问题：
推理时间过长

如果使用一个decoder架构的专精的模型，可能会有更好的效果？但是问题是训练语料的问题，如何让模型在特定场景下有独特的推理能力？一个方案能否对于已经训练好的大模型进行layer的选取，然后在将其作为初始化，然后进行微调？如果在layer中能保留这样的推理能力，然后微调让他在专精的语料上有更好的效果，减少推理时间，是否可以优化？
问题在于，如何选择layer让小模型也可以保留核心效益？
