IMDB(https://www.kaggle.com/c/word2vec-nlp-tutorial/data)电影评论数据集是一份关于电影评论的经典二分类数据集。电影观众对一部电影进行评论时可以进行打分，分值范围通常为1~10，1是观众给予的最差评分，表示对电影非常不满；10是满分，表示对电影非常满意。IMDB数据集将消费者对电影的评论按照评分的高低筛选出了积极评论和消极评论，如果评分高于或等于7，则认为是积极评论；如果评分低于或等于4，则认为是消极评论。
